# 开物 · Loreforge Web

本目录直接裁剪自 `open5e/open5e` 的固定提交 `c75e81100f575c4f8d8615128f21c354ba3c9ce4`，保留 Vue/Nuxt、通用目录表格、筛选、排序、分页、详情 Markdown、资料来源及 Axios/TanStack Vue Query 请求链。上游许可证见 `LICENSE.md`，原说明保留于 `UPSTREAM-README.md`。

当前是只读浏览端。资料由开发者导入后端，不提供在线编辑、登录、创作工坊或发布版本管理。

## 运行

沿用上游 Node 22 / npm 11 要求，本轮核验 Node **22.23.3**。`.nvmrc` 已固定该版本；不要为运行此项目修改其他项目的全局 Node 配置。

```sh
npm ci
npm run dev
```

默认地址：`http://127.0.0.1:5178/library`。没有 Node 22 时可临时执行：

```sh
npm exec --yes --package=node@22.23.3 -- npm ci
npm exec --yes --package=node@22.23.3 -- npm run dev
```

API 默认根地址为 `http://127.0.0.1:18087`，路径继续使用原生 `/v2/`。可以通过 `NUXT_PUBLIC_API_URL` 或开发阶段 `API_URL` 设置根地址，**不要附加 `/v2`**；SSR 和浏览器使用同一个 Nuxt runtimeConfig 值。这里没有 API 代理，也没有官方 API 回退；跨端口本地访问需要后端允许对应浏览器来源。

## 保留与裁剪

保留 `/spells`、`/equipment`、`/magic-items`、`/rules`、`/conditions`、`/sources` 的目录与详情。首页跳转 `/library` 联合目录，默认 `xianxia-core` 来源，可搜索名称、筛选11类、翻页及跳转原生详情。增加 `/rules/entries/<key>` 单条正文页。其余原分类页面默认读取全部来源。

已删除职业、种族、背景、专长、怪物、全站搜索、旧分类兜底和旧地址重定向页面；直接访问这些地址返回 404。遭遇构建器、工具栏、骰子、来源选择弹窗、问题上报、官方推广及统计插件退出当前应用。没有复制或依赖上游 public 品牌/插画素材，图标使用原依赖中的 Heroicons，本地渲染。

环阶、学派、职业、原规则货币、同调与稀有度保留原有含义；中文资料不等于已经确定修仙玩法。法术职业筛选已关闭，底层数据关系保留。境界、功法和图鉴显示分类规则正文。

状态正文按 `descriptions` 中的资料来源呈现，不把状态标识所属来源当作正文版本。资料页保留出版者、许可和原文链接。来源元数据可以保持原语言。

保留 `MdViewer` 组件接口，内部采用静态 `markdown-it` 解析与 `sanitize-html` 清理，不编译 Vue 模板或生成骰子交互。旧 VueShowdown/Showdown 依赖存在未修复的运行告警，已移除；表格、标题层级和行内呈现均有测试。结构化跨引用悬浮工具已随工具功能裁掉，普通 Markdown 链接仍可阅读。

## 验证

```sh
npm run build
npm test
npm run typecheck
```

保留当前路由相关上游测试，并增加正文不执行 Vue 表达式、不保留脚本/危险链接的检查。构建和单测不代替浏览器验收；本轮浏览器检查由主任务使用真实本地 API 完成。


SSR 回归需要后端已导入 starter、cultivation 与 xianxia 三批资料。先停止自己启动的5178开发服务，构建后在一个终端启动生产预览：

```sh
NITRO_HOST=127.0.0.1 NITRO_PORT=5178 npm run preview
```

另一个终端执行 `npm run test:ssr`，默认检查 `http://127.0.0.1:5178`。它检查实际HTML正文中的资料及链接，不把 hydration payload 中存在数据当成服务端已渲染。Nuxt 的客户端测试转换会移除 `onServerPrefetch`，因此没有用客户端环境中的 `createSSRApp` 冒充SSR验证。

本轮将 Vue 锁定为 `3.5.43`，与 Nuxt 所需范围对齐并去重，避免两个Vue运行时导致空 `RouterLink` 和 hydration mismatch；保留正常Nitro打包，不靠手工复制运行依赖或关闭SSR解决。

## 修仙试录读取

凡人流资料新增直接分类导航：修行入门、术法与器物、天地见闻三组包含11类。旧原生分类保留在“其他资料入口”，旧URL继续可读。联合目录改为名称、分类与正文摘录，`/library` 支持 `kind`、`q`、`source`、`page` 查询参数；默认来源 `xianxia-core`，`source=all` 表示全部来源。筛选与页码可刷新、分享和通过浏览器返回，详情的返回入口保留最近查阅位置。无效页码或读取失败保留筛选，并提供重试/回到第一页；失败结果与正常结果均保持服务端与客户端首屏一致。

`gamesystem=xianxia` 的四类原生详情使用统一阅读组件：原文显式标题和粗体段首整理为章节，正文及出处保留；手机目录可展开，宽屏目录随页固定，相关条目使用站内导航。没有从正文生成新规则或修改数据库。手机主导航支持关闭、Escape及焦点约束，关闭时不保留隐藏导航焦点。阅读验收及截图见 [本次改进](../design/library-reading-2026-09-28/README.md)。

法术与魔法物品列表增加资料来源筛选，状态按说明来源筛选；同名SRD和修仙条目保持独立。选中修仙来源后显示作用范围/持续时间或器物类别，不显示不适用的5e筛选。空环阶/学派不显示为0，未知同调不显示为否。详情展示“施加状态”“可施展法术”链接；空发布日期、网址和许可不补造。筛选在同一页面的详情往返中保留，来源选项由本地API读取。原生列表保留页面内筛选状态；可分享筛选网址目前由联合目录提供。

## 境界主线（2026-09-29）

境界分类通过目录接口的sequence排序显示八境界，条目头部以API返回的reading_neighbors提供前后阅读入口；不由前端关键词或名称猜测次序。境界总览仍使用原生规则章节页，说明八境界及单列飞升过程的关系。大乘正文可以跳到渡劫飞升；原有筑基丹、法宝、功法与洞府的关联均有具体用途说明。当前总内容107条，未接入游戏进阶。
