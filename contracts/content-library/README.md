# 游戏资料库内容格式 v1（草案）

> 状态：**草案，待 Feno 审定**。由 Claude 与 Feno 讨论后起草（2026-11-07），用于第一个大版本。
> 审定后交由后端（Codex）在 `wenxianlu-library` 与 `apps/game-runtime` 中实现读取、校验与开局冻结；
> 前端图鉴与行囊展示由 Claude 实现。

## 1. 目标

第一个大版本采用**通俗修仙小说（凡人流）的世界观与设定**：炼气、筑基、金丹、灵石、法器、丹药、坊市、宗门。
看过修仙小说的读者不需要学习新名词就能上手。

资料库的作用是**限制 AI 随意生成内容**：

- **资料**决定世界里有什么（境界、物品、功法、地点、人物）；
- **规则**决定事情怎么发生（强弱、价格、获取来源、效果边界）；
- **状态**记录当前情况（命卷存档，由运行时维护）。

AI 只负责“怎么写”，不负责“发生什么”。凡是会影响修行、战斗、经济平衡的东西，都必须引用本资料库的条目，
服务端按条目里的硬字段校验；资料库里没有的修行物品，服务端直接拒绝。

| 开局身份 | 从凡人起步：测灵根 → 拜入宗门 → 第一次引气入体（开篇剧情需重写，另行设计） | 2026-11-07 |

## 3. 通用字段（所有条目）

沿用 `wenxianlu-library` 现有的公共字段与版本机制：

| 字段 | 类型 | 说明 |
|---|---|---|
| `key` | string | 稳定编号，小写英文加连字符，创建后不可修改 |
| `name` | string | 中文名称 |
| `aliases` | string[] | 别名，用于检索和识别同一事物的不同叫法 |
| `description` | string | 是什么（玩家和 AI 都会读到） |
| `usage` | string | 用途与用法 |
| `limitations` | string | 限制与风险 |
| `source` | string | 来源说明。原创写“问仙录原创设定”；通用修仙概念写“通用修仙设定” |
| `revision` | integer | 内容版本，内容变化自动递增（由资料库维护） |
| `content_hash` | string | 内容校验值（由资料库计算，不手写） |

> 关于来源：可以使用修仙小说的**通用概念**（炼气、筑基、灵石、筑基丹等），但具体名称、人物、宗门和
> 描述应为问仙录自有内容，不照搬某一部小说独有的设定。

## 4. 境界（`realms`）

Schema：[`realm-v1.schema.json`](realm-v1.schema.json)

| 字段 | 类型 | 说明 |
|---|---|---|
| `order` | integer | 大境界顺序，凡人为 0，炼气为 1，依次递增。服务端用它比较强弱 |
| `detail` | `full` / `placeholder` | 第一版只把凡人、炼气、筑基写成 `full`，其余为占位 |
| `stages` | `{key, name}[]` | 小阶段，按顺序排列 |
| `lifespan_years` | integer | 参考寿元（岁），供叙事与 NPC 衰老使用 |
| `can` | string[] | 这个境界**能做到**的事；AI 只能在此范围内描写主角能力 |
| `cannot` | string[] | 这个境界**做不到**的事；服务端据此拒绝越界结果 |
| `breakthrough` | object | 突破到本境界的条件：`requires`（必要条件）、`aids`（辅助物品的 key）、`risk`（失败后果） |

### 强弱规则（由服务端执行，不写进每条资料）

1. 同一大境界内，小阶段差距可以靠功法、法器、准备、地形和人数弥补；
2. 相差一个大境界，低境界一方正面基本无法取胜，只能逃跑、智取或借助外力；
3. 相差两个及以上大境界，低境界一方没有正面取胜的可能；
4. 凡人对任何修士都不能正面取胜。

> 与 `AGENTS.md` 的关系：`AGENTS.md` 写有“当前不建设精密战力计算”。上述规则只比较大境界顺序，不计算战力数值，
> 属于“粗粒度边界”，需 Feno 确认后同步更新 `AGENTS.md`。

## 5. 物品（`items`）

Schema：[`item-v1.schema.json`](item-v1.schema.json)

### 5.1 分类与品阶

| 分类 `category` | 中文 | 品阶 `grade` 可选值 | 第一版范围 |
|---|---|---|---|
| `spirit_stone` | 灵石 | 下品、中品、上品、极品 | 下品、中品 |
| `pill` | 丹药 | 一品 … 九品 | 一品至三品 |
| `talisman` | 符箓 | 一品 … 九品 | 一品至三品 |
| `herb` | 灵草 | 一品 … 九品 | 一品至三品 |
| `material` | 材料 | 一品 … 九品 | 一品至三品 |
| `artifact` | 法器 | 下品法器、中品法器、上品法器、极品法器、法宝、灵宝 | 法器四档 |
| `manual` | 功法典籍 | 黄阶下品 … 天阶上品（黄/玄/地/天 × 下/中/上） | 黄阶 |

**凡物（`mundane`）不进入资料库**：衣服、纸条、竹筐、普通饭菜等由 AI 在剧情中自由创建，但服务端强制：
没有品阶、没有修行效果、不能换成灵石。

### 5.2 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `category` | enum | 见上表 |
| `grade` | string | 必须是该分类允许的品阶 |
| `rarity` | `common` / `uncommon` / `rare` / `precious` | 常见 / 少见 / 稀有 / 珍稀 |
| `realm` | realm key | 主要适用的境界（背景参考，不是使用门槛） |
| `price` | `{currency, min, max, unit}` | 参考价格区间。`currency` 为 `spirit_stone` 或 `silver`；`unit` 为“下品灵石”或“两” |
| `obtain` | enum[] | 获取途径：`market` 坊市、`sect` 宗门发放、`gather` 野外采集、`craft` 炼制、`monster` 妖兽所得、`secret_realm` 秘境、`reward` 奖赏 |
| `found_in` | string[] | 在哪类地方能遇到（地点 key 或场所类型 key） |
| `stackable` | boolean | 能否叠放计数（丹药、灵石可以；法器一般不可以） |
| `effect` | `{type, note}` | 效果类型与说明。`type` 见 5.3 |
| `side_effects` | string | 副作用，如丹毒、反噬，没有时留空 |

### 5.3 效果类型（第一版）

| `type` | 含义 |
|---|---|
| `cultivation_boost` | 加快修炼 |
| `breakthrough_aid` | 辅助突破（不保证成功） |
| `heal` | 疗伤 |
| `restore_spirit` | 恢复法力 |
| `sustenance` | 辟谷充饥 |
| `protect` | 防护 |
| `attack` | 攻击 |
| `movement` | 身法、赶路 |
| `storage` | 收纳 |
| `utility` | 其他辅助用途 |
| `material` | 只作材料，本身无直接效果 |
| `currency` | 货币 |

### 5.4 服务端规则（由后端实现）

1. **修行物品必须有出处**：AI 提出的任何非凡物物品必须引用资料库的 `key`；资料库里没有的，整回合不落库。
2. **稀有度与地点相称**：每个地点有可出现的最高稀有度（见 7.1 `max_rarity`）；超出的物品不能在该地点获得。
3. **获取途径必须匹配**：例如 `obtain` 不含 `gather` 的物品，不能写成在野外捡到。
4. **交易必须付钱**：买入要同时扣除货币并增加物品；成交价超出参考区间时需要剧情理由（议价、急售、黑市），
   具体容忍范围由后端与 Feno 商定。
5. **效果不能超出资料**：AI 不能把一枚聚气丹写成直接突破一层。
6. **灵石逐级 1:100 兑换**；灵石与银两之间没有固定汇率，只能通过剧情中的真实交易换取，并记录双方流水。

> 与 `AGENTS.md` 的关系：“固定物价模拟”目前被列为不建设。这里只给参考区间、不做物价模拟，需 Feno 确认后同步更新。

## 6. 灵根（`roots`）

开局测灵根需要。第一版字段（Schema 待物品、境界审定后补齐）：

| 字段 | 说明 |
|---|---|
| `kind` | 天灵根 / 异灵根 / 双灵根 / 三灵根 / 四灵根 / 五灵根 |
| `rarity` | 同物品稀有度 |
| `speed` | 修炼速度描述：极快 / 快 / 中等 / 慢 / 极慢（只做叙事与节奏参考，不是数值公式） |
| `elements` | 对应五行（金木水火土；异灵根为风、雷、冰等） |
| `prospects` | 宗门对此灵根的一般态度 |

## 7. 地点、势力、人物（字段预告）

第二批再细化，先列出必要字段，便于后端预留：

### 7.1 地点（`places`）

`key`、`name`、`type`（城镇 / 坊市 / 宗门 / 野外 / 秘境）、`parent`（所属上级地点）、`danger`（安全 / 低 / 中 / 高）、
`max_rarity`（可出现的最高稀有度）、`products`（出产物品 key）、`description`。

### 7.2 势力（`factions`）

`key`、`name`、`type`（宗门 / 家族 / 商会 / 散修聚落）、`stance`（立场）、`seat`（驻地地点 key）、`strongest_realm`（最强者境界）。

### 7.3 核心人物（`characters`）

`key`、`name`、`realm` + `stage`、`identity`、`personality`、`faction`、`location`、`holdings`（持有物品 key）、`goal`。
人物资料只描述“初始设定”；登场后的变化由命卷状态记录，不回写资料库。
