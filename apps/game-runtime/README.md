## 协议与事实

API `/api/runtime/v1`：`POST /sessions` 建立本地测试会话与命卷，`GET /save` 读取当前确认结果，
`POST /actions` 提交 `{request_id, expected_revision, action}`，`GET /actions/{request_id}` 恢复。
Bearer 会话仅属于新测试库，数据库只保存其散列；不开通旧账号、注册、付费和运营权限。
请求状态为 PROCESSING / COMMITTED / FAILED / UNKNOWN；它们不直接作为玩家文案。
模型协议见 `domain.py`，提示词见 `resources/narrator.md`。

当前状态使用可审计增量；模型不能换身份、覆盖旧回合、删除历史或写会话/版本。
变更要求说明本轮原因。来源、人物声明、传闻与计划分开记录；公开定义不产生「拥有/学会」事实。
每回合冻结实际取用的资料响应、revision 和 content_hash；首次用到的定义固定到本局版本，以后通过修订 API 读取。
完整回合永久保存，最近 3 回合随当前状态装配；更早回合可分页读取，未进入上下文不等于删除。
这些协议能验证结构与来源边界，无法仅靠代码证明 AI 语义上尊重授权，仍须真实连续回放。
