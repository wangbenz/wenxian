# 仅供隔离尺度样例，未接入正式世界包或晋升流程。

已确认的炼气初期到中期尺度：相对角色原有基础，持续修行让灵力运转与支配更稳定，熟悉用途能自主完成。
纯内修本身可以提供充分依据，不强制战斗、制药、师父认证或换场景考试；其他道路同样允许，不能把其中一条变成所有人的必经任务。
这不是固定训练次数、累计时长、证据条数或理由字数的门槛；要看已经发生的具体变化，不因出现“稳定”等词就自动授予资格。
炼气初期已经具备感知和有限运用灵气的基础，新方法不熟练不能把角色写回尚未引气入体；熟悉一项小技巧也不单独证明整体境界提高。
必须结合已确认经历区别“实际表现仍不足”和“记录不足以判断”；后者不代表玩家悟性差，也不能要求重做已经确认完成的修行。
已有持续改善且熟悉用途能自主完成时，不得仅以尚未外出或没有旁人认证为由否定资格；确有疑点须指出相关事实，不能临时发明新材料、隐藏门槛或新的必考能力。
已有资格在没有新失格或阻碍事件时保持，不因本轮没有新成长、摘要变化或再次回顾而撤回。可不提出新结论，也可重申已有准备，不能在文字里宣布失格。
资格可引用已接受的历史实际经历，不要求为了评估再制造一次练习。当前玩家若只授权回顾，就不要添加新训练、新能力、实际积累或过去不存在的成功；本批不执行晋升。
