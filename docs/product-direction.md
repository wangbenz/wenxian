# 《问仙录》当前产品方向

> 当前有效方向：V0.14 轻状态 AI 修仙叙事游戏
> 最近更新：2026-08-04

本文件只记录当前产品决策和方向变化。具体玩法以 `docs/game-design.md` 为准，Agent、接口与数据边界以 `docs/architecture.md` 为准，已经交付的版本内容以 `docs/version-history.md` 为准。

## 1. 当前方向

《问仙录》首先是一款允许玩家自由行动的 AI 修仙叙事游戏，不是依靠完整数值、固定地图和预制章节驱动的传统文字 RPG。

V0.14 的核心目标只有三项：

1. 玩家能自由描述行动，剧情保持连贯并具有修仙代入感；
2. 时间、地点、境界、物品、能力和重要人物等已经发生的事实能够长期一致；
3. 平台模型与玩家自备模型可以安全、稳定地驱动同一套游戏流程。

世界观负责提供修仙题材、种族和因果边界，不为所有玩家规定相同出身、相同成长速度、固定主线或唯一结局。

## 2. V0.2 方案状态

V0.2 的“传统文字 RPG 底座 + 大模型自由叙事”方案正式标记为**废弃方案**，不再作为当前路线或默认后续版本计划。

废弃原因：

- 完整战力、经济、职业、地图、事件和长期内容生产体系超出当前单人开发能力；
- 不完整的强规则比没有规则更容易制造裁决冲突和玩家体验问题；
- 为规则补齐大量内容会显著拖慢玩法验证和版本迭代；
- 当前玩家反馈更需要自由行动、剧情连贯和记录一致，而不是复杂数值系统。

V0.2 已有代码和设计只作为历史实验封存。V0.14 可以复用其中已经验证过的 H5 视觉外壳和通用交互，但这不代表继续采用 V0.2 的玩法、数据模型或内容生产方向。未来若重新讨论类似方案，必须作为新的产品立项重新评估，不能直接恢复为默认路线。

## 3. 明确不做的内容

当前方向不建设：

- 精密战力公式、伤害公式和自动胜负计算；
- 全世界统一物价表、复杂经济模拟和装备数值体系；
- 固定职业树、庞大技能树和必须按顺序解锁的成长路线；
- 为支撑数百回合而预制数百章主线；
- 依靠大量 Java 关键词和硬编码规则裁决玩家想象力；
- 唯一通关结局或所有玩家共享的固定成长节奏。

这些内容不是“稍后一定开发”的待办。只有真实玩家数据证明某个局部规则不可缺少时，才以最小范围单独评估。

## 4. 轻规则边界

Java 只保护不可妥协的系统事实：账号归属、存档隔离、时间、幂等、并发、数据生命周期、密钥安全、额度和原子落库。

Agent 负责理解玩家行动、生成剧情、判断局部得失和人物反应。境界、物品、能力、货币和人物关系是叙事事实，不是完整 RPG 数值模型。

例如：

- 战斗由已有境界、能力、伤势、准备、环境和剧情因果共同决定，不计算固定战力值；
- 交易由剧情提出价格和得失，服务端只保证货币与物品变化同步，不模拟全世界市场；
- 行囊只保证获得、持有、使用、售出、赠予或移除后的记录一致，不建设重量、耐久和装备评分；
- 人物只长期保存真正影响承诺、关系或后续剧情的对象，路人不强制入库。

## 5. 版本变动原则

后续开发按以下顺序判断需求：

1. 是否改善自由行动和沉浸感；
2. 是否解决已经发生事实的前后一致；
3. 是否能以轻规则实现，并由当前团队长期维护；
4. 是否经过真实 RDS、真实模型和手机 H5 验证；
5. 如果需要建立庞大规则体系，默认不进入当前版本。

每次产品方向发生变化时先更新本文件；具体实现随后更新设计、架构和版本记录，避免代码先行后再反复打补丁。

## 6. V0.14 上线门槛

以下清单是 V0.14 的唯一上线待办；精密战力、统一物价、职业树和预制长主线不属于本版缺陷或上线阻断项。

- [x] 产品与数据隔离：V0.14 使用独立命卷、回合、修正和模型偏好数据，V0.13 历史角色不迁移、不覆盖。
- [x] 数据迁移：建表脚本可重复执行；旧版有效自备密钥已迁入供应商级密钥表，迁移缺口可在管理台观察。
- [x] 回合安全：同账号写操作互斥，请求幂等，额度先校验，状态、回合、额度与用量在同一事务提交，失败不产生半回合。
- [x] 叙事事实：时间、地点、境界、物品、能力、重要人物和剧情纪事由单次结果同步更新，并允许玩家无回合消耗地修正命卷、整理物品和人物。
- [x] H5 主流程：登录、选择命卷、创角路线、历练、角色、纪事、世界、设置、平台/自备模型、手机键盘与防误触均已接入 V0.14 接口。
- [x] 旧版封存：V0.14 上线后 V0.13 只允许查阅；服务端拒绝续写、重开、创角和修改，新版 H5 提供明确旧档入口。
- [x] 管理台：供应商/模型启停与平台模型切换有合法性保护，平台密钥只展示掩码；V0.14 独立统计玩家、命卷、回合、Token、延迟、自备密钥、修正和迁移缺口。
- [x] 真实环境验证：RDS 迁移、旧密钥继承、真实模型长时间行动、实体增删、命卷修正、幂等与管理台统计已经验证。
- [x] 发布前回归：后端与管理台全量测试、H5 运行时锁/build/sites 测试、移动端人工复核、差异检查全部通过。
- [x] 发布操作：已备份 RDS、构建并部署后端/H5/管理台、切换共享版本为 V0.14，并完成测试账号线上真实模型冒烟；账号白名单继续保持开启，等待人工决定是否开放。
