> 状态：**草案，持续讨论中**。由 Feno 与 Claude 讨论整理（起始 2026-11-07）。
> 标注“待定”的条目尚未拍板，不能作为开发依据。
> 本文是第一个大版本的设计依据，取代旧版设计文档（`docs/game-design.md` 等）中与之冲突的内容。
> 我们不受现有代码和旧设计束缚，必要时可以推倒重来。

分工：Feno 负责最终决策；Claude 负责前端开发与玩法讨论；Codex 负责后端开发与部署。

## 1. 产品定位

- AI 驱动的单人修仙文字游戏。玩家通过推荐选项或自由输入推进剧情，每回合一章。
- 第一个大版本采用**通俗修仙小说（凡人流）的世界观与设定**，看过修仙小说的读者不需要学习新名词。
- 支持玩家**接入自己的 DeepSeek 密钥**游玩；设计时不以模型成本为约束。

## 2. 核心原则：AI 讲故事，服务端管规则

判断标准：**这件事会不会影响玩家的成长、资源和胜负？** 会，就由资料库和规则决定；不会，就交给 AI。

| 卡死（资料库 + 服务端规则） | 放开（AI 自由发挥） |
|---|---|
| 境界与能力边界 | 对话、心理、场景氛围 |
| 修行物品、功法、灵石 | 凡物、日常琐事 |
| 宗门、核心人物、主要地点 | 路人、小贩、临时配角 |
| 价格、获取途径、效果 | 剧情如何展开、事件细节 |
| 战斗胜负、突破成败（D20 判定） | 胜负过程如何描写 |

- AI 在剧情中临时创造的路人、凡物会记入**本局命卷**，之后保持一致，但不进入公共资料库，也不影响平衡。
- 资料库内容可以用 AI 批量起草，由人工审定后入库。

## 3. 世界观

### 3.1 两层世界

- **下界（人界）**：第一个大版本的全部舞台。凡人到渡劫的十个境界都在这里完成。
- **上界**：飞升之后的世界，留给后续大版本。第一版中只作为传说与终点出现。
- **飞升即为第一个大版本的结局**：有专门的结局章节，命卷归档为“已飞升”；后续上界玩法上线后可继续。

### 3.2 世界名（待定）

候选：天元界、苍澜界、青冥界、九霄界，或 Feno 自定。

### 3.3 下界五大域

地图随境界逐步开放，境界越高，能去的地方越远、越危险。

| 大域 | 概述 | 主要对应境界 |
|---|---|---|
| 中洲 | 主大陆。凡人王朝与正道宗门并存，宗门暗中掌控各国 | 凡人 → 元婴 |
| 万妖山脉（南） | 妖兽横行，越深越危险，深处有妖族 | 外围：炼气、筑基；深处：金丹以上 |
| 东海群岛 | 散修与海外仙山 | 金丹 → 元婴 |
| 魔域（西北） | 魔修聚集之地 | 化神以上（之前只在传闻中出现） |
| 北冥（极北） | 冰原荒漠，古战场与破碎秘境 | 化神 → 渡劫 |

各大域的格局、增减（例如是否加入佛门之地）待定。

### 3.4 世界背景（待定）

- **正魔对立**是否作为世界背景：待定。
- **长线悬念**，候选：
  - “飞升者一去不返”：上界从无消息传回，飞升之后究竟如何无人知晓；
  - “天劫千年一渡”：飞升机会极少，渡劫失败即身死道消。

### 3.5 第一版起始舞台

中洲东南边陲一个凡人小国的边境郡：

- **青溪镇**：主角家乡；
- **附近山中的宗门**（数量与名称待定，见第 6 节）；
- **一处坊市**：修士交易、散修聚集；
- **万妖山脉外围**：采药、一阶妖兽；
- **一处小秘境**：占位，留给后续剧情。

### 3.6 地点层级

所有地点都是资料库条目，按层级组织：界 → 大域 → 国度/山脉/海域 → 郡县/宗门/坊市 → 具体地点。
每个地点记录上级、危险程度、可出现的最高稀有度、出产与相关势力。
AI 只能在已有地点树内活动；资料库中尚未细化的远方地点只能以传闻提及，AI 不得自创新的大陆、大国或大势力。

## 4. 境界与成长

- 境界：凡人 → 炼气（一至九层 + 大圆满）→ 筑基（初期/中期/后期/大圆满）→ 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 飞升。
- 每个境界的能力边界（能做到 / 做不到）、寿元、突破条件写入资料库，格式见 `contracts/content-library/`。
- **强弱规则**（只比较大境界，不计算战力数值）：
  1. 同一大境界内，小阶段差距可靠功法、法器、准备、地形和人数弥补；
  2. 相差一个大境界，低境界一方正面基本无法取胜，只能逃跑、智取或借助外力；
  3. 相差两个及以上大境界，低境界一方没有正面取胜的可能；
  4. 凡人对任何修士都不能正面取胜。
- **突破门槛**：突破必须满足资料库条件（修为积累、资源、有时需机缘或心境），由服务端判定，AI 不能因玩家想快就让其突破。
- **寿元是核心压力**：游戏内时间真实流逝；寿元将尽仍未突破，角色会老死。NPC 同样衰老、突破、死亡。

## 5. 货币与物品

- 修士货币：灵石，下品/中品/上品/极品逐级 1:100。
- 凡俗货币：银两，只在凡人场景使用；与灵石没有固定汇率，只能通过剧情中的真实交易换取。
- 物品分为**修行物品**（灵石、丹药、灵草、材料、符箓、法器、功法典籍，必须引用资料库）和**凡物**（AI 可自由创建，没有修行效果）。
- 品阶、字段与服务端规则见 `contracts/content-library/README.md`。

## 6. 开局：从凡人到引气入体（第一卷开篇）

| 步骤 | 内容 | 回合 |
|---|---|---|
| 0. 创角 | 姓名、性别、凡俗出身（农家子弟、药铺学徒、镇上孤儿、落魄书生、商户之子……），AI 给候选，玩家挑选或修改 | — |
| 1. 凡人日常 | 在青溪镇讨生活，使用银两，结识镇上人物。传来消息：宗门十日后来镇上开山收徒（固定日期，时间真实流逝） | 2–4 |
| 2. 等待十日 | 从**镇上事件池**随机抽取 2–3 件（受伤修士求助、药铺失窃、可疑灵物……），玩家可准备、结交、节外生枝 | 若干 |
| 3. 测灵根 | 灵根由服务端按概率随机决定，AI 只负责揭晓过程的描写 | 1 |
| 4. 入门 | 由本局到场的宗门与灵根共同决定去向和身份 | 1–2 |
| 5. 引气入体 | 修习入门功法，首次尝试引气；**第一次使用 D20 判定**。失败不致死，耽误时日后可再试；成功进入炼气一层 | 若干 |

### 6.1 灵根概率（草案，可调）

| 灵根 | 概率 | 修炼速度 |
|---|---|---|
| 天灵根 | 1% | 极快 |
| 异灵根 | 2% | 很快 |
| 双灵根 | 10% | 快 |
| 三灵根 | 27% | 中等 |
| 四灵根 | 30% | 慢 |
| 五灵根（伪灵根） | 30% | 极慢 |

- 待定：灵根随机还是玩家选择（建议随机，可考虑提供一次重开）。
- 待定：是否可能测出无灵根（建议不会，保底五灵根）。

### 6.2 宗门

- 宗门写入资料库：名称、风格、驻地、最强者境界、**收徒规则**（何种灵根进内门/外门/杂役/不收）、各级弟子待遇、可习功法、特色物品、核心人物。
- 每局开局时，服务端从宗门资料中随机决定哪一两个宗门来青溪镇；灵根测出后，可选的路取决于到场的宗门。
- 待定：第一版宗门数量（建议 3 个：一大两小，风格各异）；是否第一版就做**散修路线**；宗门名称。

## 7. 随机性

| 层次 | 方式 | 效果 |
|---|---|---|
| 出身 | 创角时 AI 生成候选，玩家挑选 | 起点不同 |
| 到场宗门 | 服务端从宗门资料中随机抽取 | 每局遇到的师门不同 |
| 灵根 | 服务端按概率随机 | 决定去向与身份 |
| 镇上事件 | 服务端从事件池随机抽取 | 开局剧情与机缘不同 |
| 风险行动 | D20 判定（细则待定） | 成败有悬念且可信 |

## 8. 节奏与篇幅

- 每回合一章，正文 800–2000 字。
- 从凡人到飞升，**最少约 500 章**；不是硬性规定，而是由突破门槛自然撑起。
- **每个大境界是一卷**，有自己的主线、难关和结局，突破是该卷高潮。
- 三种回合节奏：
  - 剧情回合：正常推进；
  - 时间跳跃回合：“闭关三年”“赶路两月”一回合带过，时间与寿元真实减少；
  - 关键回合：突破、生死、重大转折，可以写长。

## 10. 服务端校验不能卡住玩家（硬性要求）

1. **先裁决，再让 AI 写**：服务端先判断行动是否成立、是否掷骰，确定结果与本回合可出现的物品范围，再交给 AI 在范围内描写。
2. **校验分轻重**：只有影响平衡的才是“致命”（不落库、进入修复）；可自动修正的自动修正；其余只记录不拦截。
3. **修复要快，且有兜底**：只让 AI 重写出错的状态变化部分，最多 1–2 次；仍失败则只保存正文、不保存出错的变化，或以游戏内语言给出“此念不可行”及 2–3 条可行建议。玩家看不到技术报错，失败的生成不扣点数。
4. **在最便宜的环节拦截明显越界的行动**：在调用剧情生成前用轻量判断转为“此念尚未成形”并给出建议。
5. **用数据盯住规则**：记录每条规则的触发次数与拒绝率；目标为需要修复的回合低于 5%，最终走兜底的低于 1%。

## 11. 长期记忆（硬性要求）

500 回合远超模型上下文。必须有可靠的分卷摘要与事实召回：已登场人物、已确认事实、承诺与恩怨在数百回合后仍能准确召回，不能因上下文裁剪而遗忘或改写。
