# 《问仙录》H5 试玩设定与玩法

## 产品定位

《问仙录》是一款需要联网调用叙事 Agent、但每位玩家拥有独立存档与时间线的休闲沉浸式修仙文字游戏。固定世界规则由服务端维护，DeepSeek 只在规则内生成命格、人物反应、剧情过程和下一步选择。

## 固定世界

故事发生在「玄墟界」：绝天之变后三千年，最后一批飞升者在天门前失踪，此后再无人能够证明仙界存在。宗门仍以长生之名争夺灵脉、血脉与凡人性命。

不可被 Agent 修改的规则：

- 修行需要资质、资源、传承、时间与代价；
- 世界不会围绕主角停止，NPC 会衰老、突破、背叛和死亡；
- 境界决定基础下限，功法、心境、情报、克制和环境决定实际结果；
- 死亡不可自动回档，错失的机缘不会原地等待；
- 玩家只能看到已经通过见面、调查或传讯获得的知识。

试玩种族为人族、妖族、灵族。境界路径为凡俗、引气、筑基、金丹、元婴、化神、炼虚、合道；首章只验证从凡俗走到第一次引气的过程。

## 开局流程

1. 使用真实邮箱和密码注册或登录；新账号获得 20 个平台赠送回合，同一网络 24 小时内最多注册一个账号。迁移前已存在但没有密码的老账号，以完整邮箱地址作为一次性初始化密码，首次登录后必须立即设置新密码。
2. 阅读固定世界序章。
3. 先选择性别与种族，再自定义姓名或生成符合身份风格的候选姓名；系统不得默认将未选择的玩家视为男性。
4. 选择人生倾向，可补充命格偏好。
5. 选择本世难度：普通或困难。普通更适合休闲阅读并保留合理转圜；困难资源更紧、失误后果更持久。难度在本世开启后锁定，重开时可重新选择。
6. DeepSeek 在固定世界内生成三种不同命格。
7. 玩家选择命格后，DeepSeek 按种族、出身与所求随机生成 1—3 个低阶先天天赋。
8. 可选其一、免费重抽一次，或不携带天赋入世；确认后才开始流动世界时间。

天赋面向玩家时采用小说化表达，只呈现异象、倾向和含蓄隐患，不公开成功率、百分比加成、冷却、每日次数或系统触发条件。后端仍保存边界、次数和恢复条件作为裁决依据，但这些属于世界运行规则，不是角色可见的 RPG 技能面板。

## 核心循环

每轮是一章约 800—1200 字、6—10 段的完整剧情，连续推进二至四个场景。正文最低合格线为700字，700–999字不因长度触发整章重写。赶路、寒暄和普通观察由 Agent 自然处理，只在会改变命运、资源、关系或风险的节点提供二至四个快捷选择，同时保留自由行动输入。Java 先校验输入，Agent 结合权威状态、历史摘要与最近必要消息提出裁决，Java 再校验时间、境界、人物、物品和能力变化，最后原子写入数据库。

前六回合优先保持休闲体验：一般失败转化为伤势、债务、风险上升或错失机缘。只有玩家在看到明确高危警告后仍作出自杀式行动，才会进入真实死亡判定。

自由输入先产生独立的行动裁决：

- `ACCEPTED`：行动明确且在当前处境中可能成立，生成完整章节并更新世界；
- `REJECTED`：违反境界顺序、使用不存在的物品或能力、改写既定历史，或当前条件显然无法完成；
- `CLARIFY`：对象或意图不明确，需要玩家补充后才能行动。

`REJECTED` 与 `CLARIFY` 属于世界规则的正常回应，不是接口错误。历练页直接展示「此念不可行」或「此念尚未成形」、具体原因及二至三条可行建议。它们不推进世界时间、不增加正式回合、不改变人物状态、不写入纪事，也不会被 Agent 改写成反噬、梦境或替代剧情；原输入与裁决会保留在命卷会话中，便于维持边界一致。纯随机数字、重复字符和简单填充词直接进入 `CLARIFY`，不调用剧情生成。

开局前三回合属于命格补完期：玩家可补充一项普通背景事实或一项有明确边界、次数和代价的低阶先天天赋。强行声明高阶力量会被拒绝或削弱；一旦剧情接受持久能力，角色页必须同步出现对应记录。第三回合后，新增能力必须有修炼、物品、血脉觉醒或事件来源。

## H5 页面

- 历练：场景、正文、对话、风险、选项和自由输入。
- 角色：身份、境界、寿元、此生所求、旧债、天赋、功法与行囊的纯展示页。
- 纪事：统一世界时间线、突破、生死、承诺与重大得失。
- 世界：已知地域、势力、人物、未解线索和剧情线。

世界页同时提供版本纪事。已发布版本可以仅作为历史记录，也可以设置为全员公告；全员公告在玩家下次进入时以自定义水墨弹层展示一次，阅读状态由服务端记录，不使用浏览器原生弹窗。运营还可以将一条重要公告固定展示在登录首页，无需登录即可查看，后续普通版本日志不会自动覆盖它。

历练页显示当前账号的赠送回合用量。新账号默认获得 20 个平台回合，额度由管理台统一调整但不会每日重置；用完后可在世界页接入自己的 DeepSeek 密钥继续游玩。自备密钥调用不消耗赠送回合，可随时移除；注销账号会同时永久删除命卷、前世记录与自备密钥。

页面切换属于前端行为；页面数据全部来自后端。二级页面不提供使用、修炼等游戏按钮；使用物品、施展天赋、修炼功法都通过首页自然语言输入提交。业务拒绝与补充提示使用世界观内的行内卡片，不使用系统弹窗，也不与网络异常混在一起；建议行动可以直接点击再次提交。

UI 提供「宣纸」、「月夜」和「跟随系统」三种阅读外观，以及小字、标准、大字三档阅读字号；字号选择保存在本机，只调整剧情、选项与资料正文，不改变命卷数据。夜间主题使用独立的月下宣纸背景、暖白正文与高遮罩暖墨色卡片，不是简单反色，长篇剧情和四个主页面标题必须保持可读。登录邮箱、密码等数据输入统一使用系统无衬线字体，避免楷体数字和符号变形。手机键盘弹出时底部导航隐藏，当前输入框自动滚入可视区域，首页行动框紧贴键盘上方。

玩家界面只使用世界观内文案，不展示模型名称、编程语言、服务端组件、数据库或接口术语。加载、同步、离线和失败状态分别用「命卷推演」「命卷已同步」「命卷暂时封存」「天机紊乱」表达；具体模型与运行诊断只保留在后端日志和开发文档中。

体力、悟性、银钱、追查和线索危险度继续作为隐藏裁决数据保存，但不以属性格、进度条、百分比或精确数字展示。角色身体与线索危险只使用「气息虚弱」「暗流渐起」等小说化状态；资源变化由剧情和行囊自然体现。

## 试玩范围

第一章目标为八至十二次关键选择，覆盖不同种族命格、命格补完、自由行动、人物关系、物品或能力获得、时间推进和至少一种失败结局。减少无意义的频繁点击，优先验证单次选择后 3—5 分钟的沉浸阅读体验。暂不包含多人、商城、排行榜、自由地图、战斗动画、复杂装备强化和 SSE 流式输出。

V0.11 同步提供内部管理台：运营概览、近 7/14 日注册趋势、账号去重的开局激活漏斗、当前在线玩家、逐次模型调用账本、平台/自备密钥与输入/输出/缓存 Token 拆分、玩家筛选与完整邮箱、当前/历史角色、前世终结原因、无限分页回合、版本公告、V4 Pro/Flash 切换、账号赠送回合、账号安全状态、临时密码、登录解锁及操作记录。“当前在线”指最近15分钟有访问的玩家；连续12小时无活动则需重新登录。Token 调用账本从功能启用时开始统计，不用旧回合记录反推平台费用。暂不加入最大 AI 并发、自动模型路由、在线 Prompt 编辑、多管理员权限或复杂运营分析。
