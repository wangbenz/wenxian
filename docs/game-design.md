# 《问仙录》H5 试玩设定与玩法

## 产品定位

《问仙录》是一款需要联网调用叙事 Agent、但每位玩家拥有独立存档与时间线的单人修仙文字 RPG。固定世界规则由服务端维护，DeepSeek 只在规则内生成命格、人物反应、剧情过程和下一步选择。

## 固定世界

故事发生在「玄墟界」：绝天之变后三千年，最后一批飞升者在天门前失踪，此后再无人能够证明仙界存在。宗门仍以长生之名争夺灵脉、血脉与凡人性命。

不可被 Agent 修改的规则：

- 修行需要资质、资源、传承、时间与代价；
- 世界不会围绕主角停止，NPC 会衰老、突破、背叛和死亡；
- 境界决定基础下限，功法、心境、情报、克制和环境决定实际结果；
- 死亡不可自动回档，错失的机缘不会原地等待；
- 玩家只能看到已经通过见面、调查或传讯获得的知识。

试玩种族为人族、妖族、灵族。境界路径为凡俗、引气、筑基、金丹、元婴、化神、炼虚、合道；首章只验证从凡俗走到第一次引气的过程。

## 开局流程

1. 邮箱与邀请码进入内部试玩；已登记邮箱后续无需邀请码。
2. 阅读固定世界序章。
3. 自定义主角姓名，或使用本地姓名库换一批。
4. 选择种族、性别和人生倾向。
5. DeepSeek 在固定世界内生成三种不同命格。
6. 玩家选择命格后，DeepSeek 按种族、出身与所求随机生成 1—3 个低阶先天天赋。
7. 可选其一、免费重抽一次，或不携带天赋入世；确认后才开始流动世界时间。

## 核心循环

每轮是一章约 1200—2000 字、10—16 段的完整剧情，连续推进二至四个场景。赶路、寒暄和普通观察由 Agent 自然处理，只在会改变命运、资源、关系或风险的节点提供二至四个快捷选择，同时保留自由行动输入。Java 先校验输入，Agent 结合本世连续消息与权威状态提出裁决，Java 再校验时间、境界、人物、物品和能力变化，最后原子写入数据库。

前六回合优先保持休闲体验：一般失败转化为伤势、债务、风险上升或错失机缘。只有玩家在看到明确高危警告后仍作出自杀式行动，才会进入真实死亡判定。

无效内容（如纯随机数字、重复字符或简单填充词）不推进时间、不写入事件，也不调用剧情生成。

开局前三回合属于命格补完期：玩家可补充一项普通背景事实或一项有明确边界、次数和代价的低阶先天天赋。强行声明高阶力量会被拒绝或削弱；一旦剧情接受持久能力，角色页必须同步出现对应记录。第三回合后，新增能力必须有修炼、物品、血脉觉醒或事件来源。

## H5 页面

- 历练：场景、正文、对话、风险、选项和自由输入。
- 角色：身份、境界、寿元、身体、心境、天赋、功法与行囊的纯展示页。
- 纪事：统一世界时间线、突破、生死、承诺与重大得失。
- 世界：已知地域、势力、人物、未解线索和剧情线。

页面切换属于前端行为；页面数据全部来自后端。二级页面不提供使用、修炼等游戏按钮；使用物品、施展天赋、修炼功法都通过首页自然语言输入提交。输入失败时保留草稿，成功写入时才清空。

UI 提供「宣纸」、「月夜」和「跟随系统」三种阅读外观；夜间主题使用独立的月下宣纸背景、暖白正文与高遮罩暖墨色卡片，不是简单反色，长篇剧情和四个主页面标题必须保持可读。登录邮箱、邀请码等数据输入统一使用系统无衬线字体，避免楷体数字和符号变形。手机键盘弹出时底部导航隐藏，当前输入框自动滚入可视区域，首页行动框紧贴键盘上方。

## 试玩范围

第一章目标为八至十二次关键选择，覆盖不同种族命格、命格补完、自由行动、人物关系、物品或能力获得、时间推进和至少一种失败结局。减少无意义的频繁点击，优先验证单次选择后 3—5 分钟的沉浸阅读体验。暂不包含多人、商城、排行榜、自由地图、战斗动画、复杂装备强化和 SSE 流式输出。
