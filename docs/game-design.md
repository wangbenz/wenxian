# 《问仙录》H5 试玩设定与玩法

## 产品定位

一款以自然语言为核心操作方式的残酷修仙文字游戏。玩家负责做决定，Agent 负责解释意图、推进世界、给出后果，并把所有变化写回统一存档。

试玩版本只验证四件事：剧情是否愿意继续读、自由行动是否有反馈、人物与时间是否保持一致、状态页是否能帮助玩家理解长期世界。

## 核心循环

1. 阅读当前场景、风险与已知事实。
2. 点击快捷行动，或用自然语言描述自己的做法。
3. Agent 根据当前时间、角色状态、线索与风险决定结果。
4. 世界时间推进；玩家、NPC、关系、事件与未解线索同步更新。
5. 玩家在「角色 / 纪事 / 世界」中核对状态，再继续历练。

## 世界原则

- 世界不会围绕玩家静止；重要 NPC 离场后仍会按自己的目标变化。
- 修为只是能力的一部分，情报、资源、承诺、克制和环境同样决定结果。
- 失败不会总是读档，也可能形成伤势、债务、错失机缘或新的敌人。
- 玩家最新的明确设定高于 Agent 的自动补充，但重大修改必须写成事件，不能静默覆盖历史。
- 玩家只看到「已知状态」；角色的真实状态由数据层单独保存，需通过见面、传讯或调查解锁。

## 试玩章节

地点为柳溪村。主角林砚为救寒症妹妹林小禾，在赌坊用异常观察力赢钱后遭到追查；药商许百川用半株赤心草提出危险交易，线索最终指向北山、城南义庄和父亲失踪时留下的灰色印记。

试玩支持：

- 三到五轮连续决策；
- 快捷选项与自由文本行动；
- 体力、银钱、悟性、追查度变化；
- NPC 档案、统一世界时间线、未解线索；
- 服务端持久化存档、浏览器离线镜像与重开。

## 四个主界面

- 历练：当前场景、叙事、风险、行动选项和自由输入。
- 角色：玩家属性、登场人物、当前状态和行囊。
- 纪事：同一世界时间轴上的决策、风险与线索事件。
- 世界：当前地点、未解线索、Agent 记录状态和重开入口。

## 视觉方向

采用「墨卷纪事」：宣纸底、克制水墨、宋体正文、楷体标题、青绿色主强调色、朱砂红危险色。界面以阅读为中心，不采用传统网游的金色特效、复杂地图和密集数值面板。
